# Financial Transaction & Customer Spending Analysis

## Project Overview
This project analyzes customer shopping transactions to understand spending patterns, customer behavior, payment preferences, and shopping mall performance using Python.

## Objectives
- Analyze customer purchasing behavior.
- Identify high-revenue product categories.
- Understand payment method preferences.
- Compare spending patterns across age groups and genders.
- Analyze monthly sales and shopping mall performance.
- Identify customer segments based on spending.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The project uses the Customer Shopping Dataset, containing transaction details such as:
- Invoice Number
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price
- Payment Method
- Invoice Date
- Shopping Mall

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Missing value and duplicate analysis
4. Exploratory Data Analysis (EDA)
5. Feature engineering
6. Statistical analysis
7. Customer segmentation
8. Data visualization and dashboard creation
9. Business insights and conclusions

## Key Analysis Areas
- Category-wise revenue analysis
- Payment method analysis
- Gender-wise spending analysis
- Age group analysis
- Monthly spending trends
- Shopping mall performance
- Correlation and outlier analysis
- Customer segmentation

## Project Files
- `customer_shopping_data.csv` – Dataset
- `Financial_Transaction_&_Spending_Analysis.ipynb` – Analysis notebook

## Conclusion
This project demonstrates how Python libraries can be used to analyze customer transactions, discover spending patterns, and generate meaningful business insights through statistical analysis and visualization.
